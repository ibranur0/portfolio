Variabler

Funksjoner
fn navn(a, b) { return a + b; } eller anonymt: fn(x) {... }. Funksjoner er verdier og husker omgivelsen sin.

        
Kontrollflyt
if... { } else { }, while... { }, for x in liste { }, break, continue
